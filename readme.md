\# Indiana Structural Rupture Model (ISRM) v1.0

\#\# Status  
Public Release – February 2026    
Version: 1.0 (Closed and Archived)

\#\# Overview

ISRM v1.0 is a structural diagnostic instrument that evaluates the interaction between systemic scale and internal restraint within federated governance systems.

It produces a Structural Pressure (SP) index and classifies jurisdictions into relative structural pressure regimes.

This tool:  
\- Does not predict specific events  
\- Does not assign moral valuation  
\- Does not prescribe intervention  
\- Does not claim inevitability

It classifies structural configurations.

\---

\#\# Core Equation

SP \= (D × (1 \+ P)) / C

Where:

D \= S × TL × N    
C \= IRD × M  

S \= Scale composite    
IRD \= Internal Restraint Density    
M \= Marriage stability multiplier    
P \= Fragmentation amplifier (optional)

Reference implementation matches original PDF specification (pages 6–7).

\#\# Validation Summary

Validated across:

\- U.S. states (1990–2024)  
\- Mexico (32 states)  
\- Canada (13 provinces)

Stress tests include:  
\- Functional form comparison  
\- Monte Carlo perturbation  
\- Out-of-sample frozen bounds  
\- Decade-by-decade IRD decoupling  
\- Boundary condition mapping

No structural collapse under defined falsifier conditions.

\---

\#\# What This Is Not

This is not:  
\- A crisis predictor  
\- A collapse forecast model  
\- A behavioral control instrument  
\- A policy automation system

It is a structural classifier.
